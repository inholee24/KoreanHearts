# 용어집

기준: **시리즈 한국 정발 표기**(킹덤 하츠 III 한국어판 등), 디즈니 캐릭터는 **디즈니 코리아 공식 표기**, 파이널 판타지 캐릭터는 **FF 한국어판 표기**. (2026-10-29 사용자 결정)

**52차 (2026-11-02):** KH3 한국어판 표기를 나무위키 문구로 확인해 도날드, 스퀄, 홀로우 바스티온, 100 에이커의 숲, 키블레이드 이름을 바꿈 (공식 자료 직접 확인 아님). 참고: 1.5+2.5 공식 한국어 자막이 2027년 초여름 예정 (Inven Global, 2026-10-08) -> 나오면 그 표기로 다시 맞출 것.

**주의 (근거 수준):** 아래 표는 Claude 가 기억하는 정발 표기로 만든 초안이다. 웹 검색으로는 정발 용어표를 확인하지 못했다. `확인 필요` 표시가 없는 것도 원본 대조를 거치지 않았으므로, 유저 검토에서 틀린 표기가 나오면 이 표를 고치고 `translation/kh1_evmsg.tsv` 에서 같은 표기를 함께 고친다.

## 규칙

- 같은 원문 용어는 문맥이 달라도 같은 표기를 쓴다 (고유명사, 기술·아이템·적 이름).
- 일반 명사로 쓰인 heart = **마음**, darkness = **어둠**, light = **빛**, world = **세계** (고유 명칭 "월드" 와 구분).
- 확정되지 않은 표기는 표에 `확인 필요` 로 둔다.

## 콜로세움 대회

- 대회 팀명(Jungle Vice, Shadow Battalion 등)은 음역 (정글 바이스, 섀도 버탤리언). 전체 목록은 `translation/work/b023.tsv` 를 만든 사전.
- `9th seed` = `9번 시드`, `Gold Match / Platinum Match` = `골드 매치 / 플래티넘 매치`, `Don't enter.` = `참가하지 않는다`.

## 말투 (번역 원칙)

- 소라, 리쿠, 카이리, 도널드, 구피끼리는 반말. 도널드·구피는 임금님께 존댓말.
- 상점 주인, 안내 NPC, 시스템 안내문은 존댓말 (`~요`, `~니다`).
- 모그리는 말끝에 "쿠뽀".
- 구피의 감탄사 "Gawrsh" = "어휴" 류, "A-hyuck" = "아휵".
