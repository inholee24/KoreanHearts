# 프로젝트 컨텍스트

## 목적

KINGDOM HEARTS Re:Chain of Memories (Steam PC판 HD 1.5+2.5 ReMIX) 한국어 번역 및 한글화.

## 방식 (KH1 과 같은 틀)

게임에는 한국어 옵션이 없다. 영어판이 읽는 언어별 파일(텍스트 `.ctdl`, 글꼴 이미지·폭/매핑 표)을 한국어용으로 만들어 Panacea 가 원본 대신 읽게 한다. 원본 pkg 는 고치지 않는다.

KH1 과 다른 점 (2026-11-04 조사, [file-formats.md](file-formats.md)):

- 텍스트 포맷이 다르다 (`@CTD`, 1바이트 ASCII). KH1 도구를 그대로 쓸 수 없다.
- 글자 폭과 문자코드→글리프 매핑이 실행 파일이 아니라 데이터(`*_sysfont.binl`, `*_evtfont.binl`)에 있다. (추론) KH1 에서 필요했던 exe 분석·메모리 패치가 필요 없을 수 있다.

## 현재 단계

**PoC 1~3 완료 (2026-11-04).** 영어 모드는 UK .ctdl 을 읽는다. 글꼴 png·매핑·폭 표(binl) 교체가 적용되고, 한자 영역 코드에 새 글리프를 연결해 한글을 표시할 수 있다 (게임 화면 확인). 실행 파일·메모리 패치 없이 데이터 교체만으로 가능. 한글 칸 sysfont 963, evtfont 1,339.
