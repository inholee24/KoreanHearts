# Re:COM 용어집

시리즈 공통 용어(인물, 월드, 기술, 아이템 등)는 **KH1 용어집 [../../kh1/docs/terminology.md](../../kh1/docs/terminology.md) 을 따른다.** 같은 원문은 두 타이틀에서 같은 표기를 쓴다. 공통 용어를 바꿀 때는 KH1 용어집을 고치고 두 타이틀의 번역 표를 함께 확인한다.

기준: 시리즈 한국 정발 표기(KH3 한국어판 등). **아래 표는 Claude 가 기억하는 표기로 만든 초안이며 공식 자료로 확인하지 못했다** (KH1 용어집과 같은 근거 수준). `확인 필요` 는 특히 근거가 약한 것. 1.5+2.5 공식 한국어 자막(2027 예정)이 나오면 다시 맞춘다.

## 말투 (KH1 규칙 + Re:COM)

- 소라·도날드·구피·리쿠끼리 반말, 도날드·구피는 임금님께 존댓말. 시스템 안내·도움말·튜토리얼은 존댓말.
- 모그리 말끝 "쿠뽀". 구피 "Gawrsh" = "어휴", "A-hyuck" = "아휵". 도날드 "Wak" = "꽥".
- XIII 기관 단원은 소라에게 반말 (위압적·비꼬는 말투). 나미네는 조용한 존댓말이 아닌 부드러운 반말 (소라와 동갑 친구 관계로 등장) `확인 필요: 장면을 보고 조정`.

## 대사 처리 메모 (WORLD)

- 지미니는 제페토를 "제페토 씨", 피노키오는 "아빠". 헤라클레스는 필에게 존댓말. 벨·야수는 서로 존댓말 (야수 "~소/~오").
- 필 "Two words ... You / ain't / heroes!" = "두 마디만 하지. / 너흰 / 영웅이 / 아니야!" (세 조각이라 소라의 "세 마디였지"와 맞음). "Everyone / is / pooped!" = "모두 / 다 / 뻗었다!".
- 푸의 "looking for nobody" 말장난 = "아무도"를 찾는다 (FORM 장면 제목 "아무도 찾지 않아"와 같은 계열).
- 선택지 메시지(질문\n      선택1\n      선택2)는 앞 공백 수를 원문 그대로 둔다.

## 대사 처리 메모 (MVS 이벤트 장면 자막)

- 액셀 "Got it memorized?" = "기억했어?". 마르실루아·비크센·렉세우스·제크시온은 "~다/~군" 위압체, 락신·액셀은 비꼬는 반말.
- 리쿠 편 목소리 = DiZ (안셈인 척) -> "~다/~느냐". 리쿠는 임금님께 존댓말, 마지막 "Fair enough, Mickey." = "알았어, 미키." (말투 전환이 장면의 요점).
- 나미네는 소라에게 반말, 마르실루아·락신에게 존댓말. 리쿠 레플리카는 반말.
- 자막은 고정 창 400px / 2줄 (`recom_tr.py` 가 검사). 한자·특수 기호 금지 (글꼴에 없음).

## 표기 메모

- 영어 글꼴 표에 없는 ASCII: `$ \ ^ ` "`" ` | ~` (□ 로 나옴) -> 범위는 `2-6층` 처럼 하이픈. `recom_tr.py apply` 가 검사한다.
- 버튼 아이콘 `[F5 xx]` 바로 뒤에 조사를 붙이지 않는다 (아이콘 이름의 받침을 모름) -> "[F5 67] 버튼으로".
- 카드 도움말은 줄 수가 화면 배치를 정한다 (이름 / 횟수 / 내성 / 빈 줄 / 능력). 내성 줄 + 빈 줄 합계를 원문과 같게.
- 마법 단계 (KH1 번역 그대로): 파이어/파이라/파이가, 블리자드/블리자라/블리자가, 선더/선다라/선다가, 큐어/큐라/큐어가 (KH1 안에서도 큐라·큐어가가 섞여 있음 - 공식 표기 확인 시 함께 고침), 그래비티/그래비라/그래비가, 스톱/스톱라/스톱가, 에어로/에어로라/에어로가.
- 기술·카드 이름은 `recom/tools/recom_kh1terms.py` 로 KH1 번역을 먼저 찾는다.
