# 번역 규칙

## 확정된 기본 원칙

- 문장 단독 번역보다 게임 내 문맥을 우선합니다.
- 가능하면 앞뒤 대사, 화자, 장면을 확인합니다.
- 동일 캐릭터의 말투와 반복 용어의 일관성을 유지합니다.
- UI 문자열인지 대사인지 구분합니다.
- 제어문자, 플레이스홀더, ID, 줄바꿈 등 구조적 요소를 임의로 훼손하지 않습니다.
- 문자열 길이 제한이 존재하는지 확인되지 않았다면 임의로 단정하지 않습니다.
- 공식 한국어 번역이나 기존 시리즈 번역이 확인되는 경우 우선 참고합니다.

## 수정 전 확인

- 동일 원문이 다른 파일에도 존재하는지
- 기존 번역이 이미 존재하는지
- 같은 용어가 다른 문맥에서 어떻게 번역되었는지
- 문자열 내부의 제어코드/포맷 토큰이 무엇인지
