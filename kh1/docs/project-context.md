# 프로젝트 컨텍스트

## 목적

킹덤하츠 시리즈의 한국어 번역 및 한글화. 현재 작업 대상은 KH1 (KINGDOM HEARTS FINAL MIX), Steam PC판 HD 1.5+2.5 ReMIX.

## 현재 단계

**폰트 파이프라인은 대화창에서 동작이 확인되었다** (2026-09-21, 11차). 상점 아이템 설명 하나를 한국어로 바꿔 게임 안에서 표시했다.

```text
방어력을 조금
올려 준다.
```

경로 요약 ([file-formats.md](file-formats.md) 참조):

- 메시지: 1바이트 `idx + 0x20`, 2바이트 `((b0<<8)|b1) - 0x1820`
- 대화창 폭: `UK_kanji.knj` 꼬리 테이블 (`0x40080 + idx`)
- 대화창 그림: `knj0` DDS, 셀 24x32, 색은 회색 채움 + 알파 FF
- **폰트가 둘이다.** UI(상점 목록 등)는 `US_font_data_tbl.bin` + `sysfont`이며 별도 작업이 필요하다.
- 재패킹 없음. `mod\kh1\`에 같은 상대 경로로 파일을 두면 Panacea가 읽는다.

번역 자체는 아직 시작하지 않았다. 다음 결정은 [known-issues.md](known-issues.md)의 1번(글자 용량과 글자 집합)과 [work-history.md](work-history.md) 6-20 참조.

## 작업 원칙

1. 특정 파일만 보고 전체 구조를 추정하지 않는다.
2. 관련 문자열, ID, 스크립트, 패킹/언패킹 코드를 저장소 전체에서 검색한다.
3. 직접 확인한 사실과 추론을 구분한다.
4. 기존 원본/번역 데이터를 불필요하게 덮어쓰거나 삭제하지 않는다.
5. 한 번에 독립적인 변경 하나만 수행한다.
6. 변경 후에는 해시·바이트 diff와 가능한 실행 결과를 검증한다.
7. 실행 결과를 [work-history.md](work-history.md)에 기록한다.
8. **"안 보임"이 반복되면 코드 경로를 파기 전에 그림 형식, 색, 위치부터 배제한다.**
